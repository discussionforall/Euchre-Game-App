# Release notes ("What's new")

Play allows **500 characters per language**, set per release under
**Test and release → (track) → Create new release**. en-GB, matching the listing.

Version **1.0.0**, the first release. So this is an introduction, not a
changelog. Later notes should say what changed, in the player's terms.

---

## 1.0.0 — first release [397]

```
First release!

Play the classic trick-taking card game Euchre with a computer partner against two computer opponents. First team to 10 points wins.

Real rules: the right and left bowers, two rounds of bidding, stick the dealer, and going alone for 4 points.

Smooth animations, a How to play guide for newcomers, Normal or Fast speed, and your win record on the home screen. Plays fully offline.
```
